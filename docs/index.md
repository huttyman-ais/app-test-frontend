# app-test-frontend

React + TypeScript frontend for **app-test**, generated by the Backstage
`create-application` template.

- **Owner:** user:default/alice
- **Team:** group:default/payments-team
- **Environment:** dev

## Local development

```bash
npm install
npm run dev
```

## Deployment

Deploys automatically on push to `main` via `.github/workflows/ci-cd.yaml` — builds a container
image, pushes to Azure Container Registry, and updates the Azure Container App
`app-test-frontend`.
